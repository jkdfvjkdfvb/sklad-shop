# ТЗ для SEO-специалиста: корпоративные подарки, мерч, сувенирная продукция с логотипом

**Проект:** каталог сувенирной продукции / корпоративных подарков  
**Сайт:** https://sklad-shop-production.up.railway.app/  
**Цель:** подготовить SEO-структуру, семантические кластеры, посадочные страницы, товарные категории и контентные блоки для продвижения в классической поисковой выдаче и AI/генеративной выдаче.

---

## 1. Общая SEO-логика проекта

Проект относится к B2B-нише сувенирной продукции, корпоративных подарков, бизнес-сувениров, мерча и продукции с логотипом.

В выдаче и у крупных игроков рынка используются несколько разных языков спроса:

1. **Сувенирная продукция / бизнес-сувениры** — классический B2B-запрос: компании ищут поставщика сувениров под нанесение логотипа.
2. **Корпоративные подарки** — запросы от HR, маркетинга, отделов закупок и руководителей.
3. **Мерч / корпоративный мерч / welcome pack** — более современный язык спроса: брендированный мерч для сотрудников, клиентов, мероприятий, онбординга.
4. **Товар + с логотипом / под нанесение / оптом / на заказ** — самая важная SEO-маска для товарных категорий и карточек.

Главная рекомендация: **не сваливать всё на одну страницу**. Нужны отдельные посадочные под разные интенты.

## 17. Технические требования к индексации

На момент анализа сайт выглядел как каталог, но товары в HTML могли не отображаться поисковику. Для SEO критично:

1. У каждой категории должен быть отдельный индексируемый URL.
2. У каждой карточки товара должен быть отдельный индексируемый URL.
3. Товары и категории не должны быть доступны только через JS без серверной отдачи HTML.
4. Нужны ЧПУ-адреса.
5. Нужны уникальные Title, H1, Description.
6. Нужны хлебные крошки.
7. Нужна XML-карта сайта.
8. Нужен `robots.txt`.
9. Нужна микроразметка `Product`, `Offer`, `BreadcrumbList`.
10. Нужны canonical URL для карточек и категорий.

## 23. Главный принцип продвижения

**SEO-страницы ловят спрос “заказать / купить / оптом / с логотипом”, а AI/AEO-страницы ловят спрос “помоги выбрать / сравни / посоветуй / сколько стоит / что положить в набор”.**

Поэтому проекту нужны оба типа контента:

1. **Коммерческие посадочные** — для заявок.
2. **Категории и карточки товаров** — для товарного спроса.
3. **FAQ и статьи** — для AI-выдачи и информационных интентов.
