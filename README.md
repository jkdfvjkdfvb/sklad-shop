# СкладПромо — Интернет-магазин

Интернет-магазин промо-товаров с витриной, корзиной, оформлением заказов и административной панелью.

---

## Быстрый старт (локально)

```bash
npm install
npm start
```

| URL | Описание |
|---|---|
| http://localhost:3000 | Витрина магазина |
| http://localhost:3000/product/:article | Страница товара (SEO) |
| http://localhost:3000/catalog/:slug | SEO-страница категории каталога |
| http://localhost:3000/sitemap.xml | XML-карта сайта |
| http://localhost:3000/robots.txt | robots.txt |
| http://localhost:3000/admin.html | Административная панель |

Пароль по умолчанию: `admin123`

---

## Возможности витрины

- Каталог 69 товаров с фильтрами по категории, материалу и цвету (чекбоксы, OR внутри группы, AND между группами)
- Счётчики значений в фильтрах; группы с более чем 6 вариантами сворачиваются
- Иконки SVG у каждого значения фильтра; цветовые точки у фильтра по цвету
- Сортировка по цене и количеству
- Поиск по названию и артикулу
- Страница каждого товара (`/product/:article`) — server-side rendering для поисковиков
- SEO-страницы категорий каталога (`/catalog/:slug`) — 7 приоритетных категорий (брелоки, наборы, часы, портфели, открывалки, ручки, флешки) с описанием, задачами применения, способами нанесения логотипа, FAQ и перелинковкой
- Блок «Популярные категории» на главной со ссылками на SEO-страницы каталога
- Корзина (localStorage), оформление заказа, форма с именем и телефоном

---

## Возможности админки

- **Заказы:** список, статусы (новый / в работе / выполнен), модалка с деталями заказа
- **Товары:** инлайн-редактирование цены, кол-ва, видимости; загрузка фото/видео
- **Товары:** модалка редактирования — фото, название, описание, категория, материал, цвет, **SEO-заголовок и мета-описание**
- **Товары:** копирование товара (новый артикул `<артикул>-copy`, фото/видео копируются)
- **Товары:** удаление товара (с подтверждением)
- **Товары:** чекбоксы + «выбрать все», массовое сохранение и массовое удаление
- **Контакты:** редактирование hero-баннера (заголовок и подзаголовок), контактных данных и ссылок на соцсети
- **Уведомления:** настройка email (Gmail SMTP) и Telegram-бота для оповещений о заказах

## SEO и AI-оптимизация

Реализовано по ТЗ [`seo_tz_corporate_gifts_merch.md`](seo_tz_corporate_gifts_merch.md) (разделы 6–8, 10, 17–19): таксономия категорий и SEO-названия в [`server/seo-data.js`](server/seo-data.js), шаблоны Title/Description, техническая индексация и микроразметка.

### Страницы товаров (`/product/:article`)

- `<title>`: `[Название] с логотипом — купить под нанесение` (или кастомный `meta_title` из админки)
- `<meta name="description">`: авто-описание с упоминанием нанесения логотипа, опта и доставки (или кастомный `meta_description`)
- Open Graph теги (`og:title`, `og:description`, `og:image`, `og:url`), `<link rel="canonical">`
- JSON-LD: **Product** (цена, наличие, артикул, SEO-название категории, изображение) и **BreadcrumbList**
- Microdata `itemprop` прямо в HTML
- Хлебные крошки ведут на SEO-страницу категории, если она существует

### SEO-страницы категорий (`/catalog/:slug`)

Для 7 приоритетных категорий (P1 по ТЗ) — брелоки, подарочные наборы, часы, портфели, открывалки, ручки, USB-флешки:

- Уникальные Title/H1/Description по шаблонам из раздела 10 ТЗ
- Вступительный текст, блок «для каких задач подходит», способы нанесения логотипа
- FAQ (8–10 вопросов на категорию) — видимый блок + JSON-LD **FAQPage**
- Перелинковка на смежные категории (раздел 16.2 ТЗ)
- JSON-LD: **CollectionPage** + **ItemList** (список товаров) и **BreadcrumbList**
- Список товаров с добавлением в общую корзину (`/js/category.js`)

Остальные категории (P2/P3) получили только SEO-название для карточек товара — отдельные посадочные страницы можно добавить по той же схеме в `server/seo-data.js`.

### Техническая индексация

- `/robots.txt` — открывает каталог и товары, закрывает `/admin.html` и `/api/`
- `/sitemap.xml` — динамически собирается из главной, всех SEO-категорий и товаров в наличии

## Первичный импорт данных

Товары и фотографии уже включены в репозиторий (`server/data/products.json`, `public/images/`).

Если нужно перегенерировать из исходных файлов (`Контент/`):

```bash
pip install -r scripts/requirements.txt
python scripts/import_data.py
```

Скрипт читает `Склад_2019_Sale_Опт.xls` и извлекает фотографии из `Технологика_распродажа.pdf`.

## Деплой на Railway

1. Создайте репозиторий на GitHub и загрузите код
2. Зайдите на [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**
3. Укажите порт `3000` когда Railway спросит
4. В **Variables** добавьте `ADMIN_PASSWORD` и `PORT=3000`
5. В **Settings → Networking → Generate Domain** получите публичный URL

> **Важно:** для сохранения загруженных через админку фото и видео добавьте Railway Volume с путём `/app/public`. Иначе файлы сбросятся при следующем деплое.

> **Важно:** токены сессии AdminPanel хранятся в памяти сервера и сбрасываются при каждом деплое/перезапуске. После деплоя нужно войти заново.

```
public/
  index.html          — витрина
  admin.html          — административная панель
  admin-help.html     — инструкция для администратора
  css/
    style.css         — стили витрины
    admin.css         — стили админки
    product.css       — стили страниц товаров
    category.css      — стили SEO-страниц категорий
  js/
    shop.js           — логика витрины, фильтров, сортировки и корзины

  images/             — фотографии товаров
  media/              — видеофайлы товаров

server/
  server.js           — Express API + SSR страниц товаров и категорий, robots.txt/sitemap.xml
  seo-data.js         — таксономия категорий, SEO-названия, контент SEO-страниц каталога

    products.json     — база товаров
    contacts.json     — контакты, hero-баннер и настройки уведомлений
    orders.json       — история заказов

scripts/
  import_data.py      — разовый импорт из xls + pdf
  tag_attributes.js   — авто-проставление category/material/color по названиям
  requirements.txt    — Python-зависимости для импорта
```

## API

### Публичные эндпоинты

| Метод | URL | Описание |
|---|---|---|
| GET | `/product/:article` | Страница товара (SSR, SEO) |
| GET | `/catalog/:slug` | SEO-страница категории каталога (SSR) |
| GET | `/sitemap.xml` | XML-карта сайта |
| GET | `/robots.txt` | robots.txt |
| GET | `/api/products` | Список товаров в наличии |
| GET | `/api/contacts` | Контактные данные и hero-баннер |
| POST | `/api/order` | Оформить заказ |

### Административные эндпоинты (требуют заголовок `x-admin-token`)

| Метод | URL | Описание |
|---|---|---|
| POST | `/api/login` | Вход, получение токена |
| POST | `/api/logout` | Выход |
| GET | `/api/admin/products` | Все товары |
| PUT | `/api/admin/products/:article` | Изменить товар (цена, кол-во, видимость, название, описание, категория, материал, цвет, SEO-теги) |
| DELETE | `/api/admin/products/:article` | Удалить товар |
| POST | `/api/admin/products/:article/duplicate` | Скопировать товар |
| POST | `/api/admin/products/:article/image` | Загрузить фото |
| POST | `/api/admin/products/:article/video` | Загрузить видео |
| PUT | `/api/admin/products/bulk` | Массово изменить цену/кол-во/видимость |
| POST | `/api/admin/products/bulk-delete` | Массово удалить товары |
| GET | `/api/admin/orders` | Все заказы |
| PUT | `/api/admin/orders/:id` | Изменить статус заказа |
| GET | `/api/admin/contacts` | Контакты + настройки уведомлений |
| PUT | `/api/admin/contacts` | Обновить контакты, hero-баннер, уведомления |
