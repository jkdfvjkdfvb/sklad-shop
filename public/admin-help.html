Вход в административную панель

Административная панель доступна по адресу /admin.html на сайте магазина.

Для входа введите пароль. По умолчанию пароль — admin123. Рекомендуется сменить его сразу после первого входа (см. раздел Смена пароля).

Сессия сохраняется в текущей вкладке браузера. После закрытия вкладки потребуется войти снова.

📦

Работа с заказами

Список заказов

Вкладка Заказы открывается по умолчанию при входе. Число в красном кружке рядом с вкладкой показывает количество новых необработанных заказов.

В таблице отображаются: номер заказа, дата, имя покупателя, телефон, список товаров и итоговая сумма.

Просмотр деталей заказа

Нажмите на любую строку таблицы — откроется окно с полной информацией: данные покупателя, комментарий, список товаров с количеством и ценами.

Статусы заказов

Для каждого заказа можно выбрать статус в выпадающем списке прямо в таблице:

  • Новый — только что поступил, ещё не обработан
  • В работе — заказ принят в обработку
  • Выполнен — заказ выполнен и передан покупателю

Статус сохраняется автоматически при изменении.

📨

Заявки на опт

На странице каждого товара есть кнопка «Запросить оптовые условия». Когда покупатель оставляет имя и контакт, заявка попадает во вкладку Заявки на опт — и, если подключён Telegram-бот (см. раздел Настройка Telegram-уведомлений), сразу приходит уведомление.

Число в красном кружке рядом с вкладкой — количество необработанных заявок.

Что видно в таблице

Дата обращения, товар и артикул, имя, контакт (телефон или email) и комментарий покупателя.

Статус заявки

  • Новая — ещё не обработана
  • Обработана — менеджер связался с покупателем

Меняется в выпадающем списке прямо в таблице, сохраняется автоматически.

Удаление заявки

Кнопка 🗑 в конце строки — удаляет заявку без возможности восстановления.

Управление товарами

Поиск товара

Используйте строку поиска над таблицей — поиск работает по наименованию и артикулу.

Создание нового товара

  1. Нажмите «+ Новый товар»Кнопка над таблицей, рядом со строкой поиска
  2. Товар создаётся сразуЕму присваивается временный артикул вида new-xxxxxx, количество и цена — 0, товар скрыт от покупателей (переключатель «Показывать» выключен)
  3. Открывается окно редактированияЗаполните артикул, название, фото и описание (см. ниже), затем закройте окно
  4. Укажите цену и количество, включите «Показывать»Прямо в строке таблицы — товар появится на витрине только после этого

Изменение цены и количества

Поля Кол-во и Цена редактируются прямо в таблице. После изменения нажмите Сохранить в той же строке.

На сайте показывается ровно та цена, которая указана здесь — без наценок и коэффициентов. Товары с количеством 0 автоматически скрываются из витрины для покупателей.

Показывать / скрыть товар

Переключатель в колонке Показывать управляет видимостью товара на витрине. Скрытые товары не удаляются — их можно показать обратно в любой момент.

Загрузка фото, видео и фото для фидов

В колонке Медиа у каждого товара три кнопки загрузки:

  • 📷 Фото — основное фото товара: показывается на странице товара и в карточке каталога, а также используется как обложка в товарных фидах (Google Merchant, Яндекс.Вебмастер), если для товара не загружено отдельное «Фото для фида»
  • 🎬 Видео — на карточке товара в витрине появится кнопка «▶ Видео»
  • 🖼️ Фото для фида — отдельное изображение (например, с инфографикой или преимуществами товара) специально для фидов Google Merchant и Яндекс.Вебмастер. На сайте не показывается, только в выгрузках /feeds/google.xml и /feeds/yandex.yml. Рядом с кнопкой — статус «есть» со ссылкой на файл и крестик для удаления (после удаления фиды вернутся к обычному фото)

Поддерживаются форматы JPG, PNG, WebP для фото (до 20 МБ) и MP4, WebM для видео (до 200 МБ). Загрузка применяется сразу — нажимать «Сохранить» не нужно.

Загруженные файлы хранятся на постоянном диске (Railway Volume) и не теряются при следующем деплое — см. раздел Смена пароля и настройку DATA_DIR в README проекта.

Редактирование карточки товара (✏️)

Открывает окно с расширенными полями, которых нет в таблице:

  • Артикул — можно переименовать; система проверяет, что новый артикул ещё не занят другим товаром
  • Фото — то же, что кнопка «📷 Фото» в таблице
  • Наименование и Описание
  • SEO / Метатеги: заголовок страницы и мета-описание. Если оставить пустыми — формируются автоматически из названия, цены и наличия
  • Характеристики: категория, материал, цвет — поля с автодополнением по уже введённым у других товаров значениям

Нажмите Сохранить внизу окна — изменения (включая переименование артикула) применяются сразу.

Копирование товара (📄)

Создаёт копию товара с новым артикулом (<артикул>-copy), фото и видео копируются вместе с ней. Удобно для похожих товаров — остаётся поменять артикул, название и цену.

Удаление товара (🗑)

Требует подтверждения. Действие необратимо — вместе с товаром удаляются его фото, видео и фото для фида.

Массовые действия

Отметьте нужные товары чекбоксами в первой колонке (или чекбоксом «Выбрать все» в шапке таблицы) — появится панель массовых действий:

  • Сохранить выбранные — применяет текущие значения цены, количества и видимости из строк таблицы ко всем отмеченным товарам разом
  • Удалить выбранные — удаляет все отмеченные товары после подтверждения

Контакты и баннер магазина

Баннер на главной странице

Заголовок и Подзаголовок — крупный текст в баннере вверху главной страницы сайта.

Контакты

Публичные данные, которые отображаются в шапке и подвале витрины.

  • Телефон — отображается в шапке, кликабельная ссылка tel:
  • Email — отображается в блоке «Как заказать»
  • MAX, Telegram, ВКонтакте — ссылки на мессенджеры и соцсети. Вставьте полный URL (например, https://t.me/username)

После заполнения нажмите Сохранить. Изменения применяются мгновенно.

Фиды и карта сайта

Вкладка Фиды собирает ссылки, которые нужно один раз указать в сервисах для поисковых систем и маркетплейсов:

  • Google Merchant (Shopping) — товарный фид для Google Merchant Center
  • Яндекс.Вебмастер (YML) — фид «Товары и цены» для Яндекс.Вебмастера
  • Карта сайта (sitemap.xml) и robots.txt — для Google Search Console / Яндекс.Вебмастера
  • llms.txt — обзор каталога для AI-краулеров и нейросетевых поисковых ответов

У каждой ссылки — кнопки «Открыть» (посмотреть в новой вкладке) и «Копировать» (скопировать адрес в буфер обмена, чтобы вставить в кабинет Merchant Center или Вебмастера).

Фиды всегда актуальны

Все фиды формируются автоматически из текущего каталога товаров — отдельно «пересобирать» файлы не нужно. После изменения цены, наличия или фото товара фид обновится сам к моменту следующего запроса.

Кнопка «Проверить фиды» запрашивает текущее число товаров в фиде и время проверки — удобно, чтобы убедиться, что недавние правки уже учтены.

Чтобы у товара в фидах было отдельное изображение (например, с инфографикой) вместо обычного фото — загрузите «Фото для фида» в карточке товара, см. раздел Управление товарами.

Настройка Email-уведомлений

Настройки находятся во вкладке Уведомления → Email (Gmail SMTP).

При оформлении каждого заказа на указанный адрес будет приходить письмо с полной информацией о заказе.

Пошаговая настройка для Gmail

  1. Включите двухфакторную аутентификацию Перейдите в Аккаунт Google → Безопасность и включите двухэтапную верификацию
  2. Создайте пароль приложения Перейдите в Пароли приложений, выберите «Другое (произвольное название)», введите «СкладПромо» и нажмите «Создать»
  3. Скопируйте 16-значный пароль Google покажет пароль вида xxxx xxxx xxxx xxxx — скопируйте его (пробелы можно оставить)
  4. Заполните форму в админке Email для заказов, SMTP Login (ваш Gmail), SMTP Password (пароль из шага 3). Остальные поля оставьте по умолчанию
  5. Нажмите «Сохранить Email» Уведомления начнут приходить со следующего заказа
SMTP Host: smtp.gmail.com, SMTP Port: 587 — эти значения уже заполнены по умолчанию.

Настройка Telegram-уведомлений

Настройки находятся во вкладке Уведомления → Telegram-бот.

При каждом новом заказе бот отправит в ваш Telegram сообщение с именем покупателя, телефоном, списком товаров и суммой. Точно так же приходит уведомление при новой заявке из раздела Заявки на опт — с товаром, именем и контактом покупателя.

Пошаговая настройка

  1. Создайте бота Напишите @BotFather команду /newbot, придумайте имя и username для бота
  2. Получите токен BotFather пришлёт токен вида 123456789:AABBccDDeeFF... — скопируйте его
  3. Запустите бота Найдите вашего бота в Telegram по username и нажмите «Старт» или отправьте /start
  4. Узнайте свой Chat ID Напишите боту @userinfobot — он ответит вашим числовым ID (например, 123456789)
  5. Вставьте токен и Chat ID в форму Вкладка «Уведомления» → форма «Telegram-бот» → нажмите «Сохранить Telegram»
Если хотите получать уведомления в групповой чат — добавьте бота в группу и используйте Chat ID группы (начинается с минуса, например -1001234567890). Узнать ID группы можно через @username_to_id_bot.

Смена пароля

Пароль задаётся через переменную окружения ADMIN_PASSWORD на хостинге.

На Railway:

  1. Откройте Railway Dashboardrailway.app → ваш проект → сервис sklad-shop
  2. Перейдите в VariablesНайдите переменную ADMIN_PASSWORD
  3. Измените значениеВведите новый пароль и нажмите «Save». Railway автоматически передеплоит сервис
Никому не сообщайте пароль от админки. Смените пароль admin123 при первом входе.
