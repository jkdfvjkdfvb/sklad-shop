## 1. Executive Summary (Ключевые выводы аудита)

1. **Технический стек и скорость — сильнейший актив:** Сайт на Node.js с server-side rendering (`server/seo.js`) отдает чистый HTML за 6–15 мс (TTFB). LCP < 0.6 с, нулевой CLS. Сайт готов к кратному росту поискового краулинга без перегрузки сервера.
2. **Успешный старт E-E-A-T (Реквизиты и Склад подтверждены):** В футер и `server/data/company.json` интегрированы официальные реквизиты ООО «Гифтс-маркет» (ИНН 7804703609, ОГРН 1237800097512, р/с ВТБ) и фактический адрес склада в Санкт-Петербурге (Гражданский д. 118/1). Это устранило подозрение поисковых систем в «анонимном дропшиппинге».
3. **Критический юридический блокер (152-ФЗ РФ):** На сайте отсутствуют страница `/privacy` и обязательные чекбоксы согласия на обработку персональных данных в корзине и форме оптовых заявок. Это грозит штрафами Роскомнадзора до 150 000 руб. и сдерживает коммерческое доверие поисковиков.
4. **Недоохват B2B-спроса (Intent Mismatch):** В семантике более 70% маржинального спроса приходится на B2B-запросы (*«корпоративные подарки»*, *«сувениры с логотипом»*, *«подарки на Новый год»*, *«сувениры оптом»*). Сейчас каталог продвигает только штучные товары без оптовой сетки цен.
5. **Тонкие шаблоны категорий:** Страницы `/category/:slug` отдают только сырую сетку товаров без вводного текста, B2B-условий и микроразметки `BreadcrumbList` / `CollectionPage`, что снижает их шансы занять ТОП-10 в Яндексе.
6. **Готовность к AI/GEO (AEO):** Файл `/llms.txt` уже работает, но требует расширения блоками B2B-условий, минимального заказа и правил брендирования для точного цитирования в Perplexity, ChatGPT Search и Алисе.
7. **Сезонное окно возможностей:** До старта пика новогодних B2B-закупок (15 октября) необходимо за 14 дней развернуть сезонный хаб `/podarki-na-novyj-god` и сетку оптовых цен на всех 69 SKU.

## 5. Архитектурный каркас страниц (Page Block Blueprint)

### 5.1. Главная страница (`/`)
1. **Header:** Логотип, поиск SKU/название, телефон `+7 (812) 962-15-98`, мессенджеры, корзина.
2. **Hero:** H1 *«Сувенирная продукция и корпоративные подарки со склада в Санкт-Петербурге»* + бейджи:
   - 📦 *Склад в СПб (Гражданский 118/1) — отгрузка за 24 часа*
   - 📄 *Безналичный расчет, счет с НДС, УПД для юрлиц*
   - 🔍 *Образцы продукции от 1 шт.*
   - 🎨 *Брендирование и нанесение логотипа под ключ*
3. **Категории каталога:** Плиточный рубрикатор (20 категорий со счетчиками).
4. **Каталог товаров:** Фильтры (категория, материал, цвет) + сетка карточек `<article>`.
5. **Склад и самовывоз:** Адрес склада, часы работы, интерактивная ссылка на Яндекс.Карты.
6. **Как заказать (B2B процесс):** 4 шага (Выбор → Счет с НДС → Образец/Нанесение → Отгрузка).
7. **Footer:** Реквизиты ООО «Гифтс-маркет», ссылки на `/privacy` и `/delivery`, телефон, email, копирайт.

### 5.2. Карточка товара (`/product/:slug`)
1. **Хлебные крошки (`nav.breadcrumb`):** Главная › {Категория} › {Название SKU}.
2. **Экран покупки (`article.product-detail`):**
   - Галерея фото с зумом + бейдж `В наличии: X шт. на складе в СПб`.
   - Артикул, H1, материал, цвет, габариты.
   - **Оптовая сетка цен:**
     - 1–9 шт.: `price` ₽ (розница / образец)
     - 10–49 шт.: `-10%` ₽ (мелкий опт)
     - от 50 шт.: `-20%` ₽ (корпоративный тираж)
   - Кнопка 1: «В корзину» (мгновенное добавление).
   - Кнопка 2: «Запросить расчет с нанесением логотипа» (модалка B2B).
3. **Характеристики (`table.product-attrs`):** Таблица технических параметров.
4. **Возможности брендирования (`section.branding`):** Рекомендуемые методы нанесения под материал (гравировка / УФ / тампопечать).
5. **Доставка и оплата (`section.delivery-snippet`):** Самовывоз в СПб сегодня, доставка по РФ, счет для юрлиц.
6. **B2B Вопрос-Ответ (`section.product-faq`):** Аккордеон из 4 вопросов с микроразметкой `FAQPage`.
7. **С этим товаром заказывают (`section.related-products`):** Перелинковка внутри смежных групп.

```javascript
function homeProductCardHtml(product, cleanSiteUrl) {
  const slug = productSlug(product);
  const price = retailPrice(product);
  const qty = quantity(product);
  const inStockNow = inStock(product);
  const photo = product.photos?.[0] || 'images/no-photo.svg';

  return `<article class="product-card seo-card" itemscope itemtype="https://schema.org/Product" data-article="${escH(product.article)}">
  <meta itemprop="sku" content="${escH(product.article)}">
  <link itemprop="url" href="${cleanSiteUrl}/product/${encodeURIComponent(slug)}">
  <a class="product-card-image" href="${cleanSiteUrl}/product/${encodeURIComponent(slug)}">
    <img src="${cleanSiteUrl}/${escH(photo)}" alt="${escH(productName(product))}" loading="lazy" itemprop="image">
  </a>
  <div class="product-card-body">
    <div class="product-card-meta">
      <span class="product-article">Арт. ${escH(product.article)}</span>
      <span class="stock-badge ${inStockNow ? 'in-stock' : 'out-of-stock'}">${inStockNow ? `В наличии: ${qty} шт.` : 'Под заказ'}</span>
    </div>
    <h3 class="product-title" itemprop="name">
      <a href="${cleanSiteUrl}/product/${encodeURIComponent(slug)}">${escH(productName(product))}</a>
    </h3>
    <div class="product-pricing" itemprop="offers" itemscope itemtype="https://schema.org/Offer">
      <meta itemprop="priceCurrency" content="RUB">
      <link itemprop="availability" href="${inStockNow ? 'https://schema.org/InStock' : 'https://schema.org/OutOfStock'}">
      <data class="price-val" itemprop="price" value="${price}">${priceText(price)} ₽</data>
      <span class="price-note">Опт — по запросу</span>
    </div>
    <button class="add-to-cart-btn" data-article="${escH(product.article)}" ${inStockNow ? '' : 'disabled'}>В корзину</button>
  </div>
</article>`;
}
```

function wholesaleTierHtml(price) {
  const p = Number(price) || 0;
  if (p <= 0) return '';
  const tier10 = Math.round(p * 0.9);
  const tier50 = Math.round(p * 0.8);

  return `<div class="wholesale-tiers" aria-label="Оптовые цены от объема">
  <div class="tier-col active">
    <span class="tier-qty">1–9 шт.</span>
    <span class="tier-price">${priceText(p)} ₽</span>

### 6.3. Блок нанесения логотипа по материалу (`server/seo.js`)
```javascript
function brandingGuideHtml(material) {
  const mat = String(material || '').toLowerCase();
  let tech = 'УФ-печать или тампопечать';
  let desc = 'Стойкое нанесение фирменной символики компании в 1-4 цвета.';

  if (mat.includes('металл')) {

    desc = 'Вечная стойкость изображения, аккуратный монохромный контур, премиальный внешний вид.';

    tech = 'Лазерная гравировка или круговая УФ-печать';
    desc = 'Экологичное нанесение с сохранением натуральной текстуры дерева.';

    tech = 'Слепое тиснение (блинт) или фольгирование';
    desc = 'Рельефный оттиск логотипа, устойчивый к ежедневному использованию.';

    tech = 'Шелкография или термотрансфер';
    desc = 'Яркие корпоративные пантоны, стойкость к стирке и сгибам.';
  }

  return `<section class="product-branding-info">
  <h3>Нанесение логотипа</h3>
  <p><strong>Рекомендуемая технология:</strong> ${escH(tech)}.</p>
  <p>${escH(desc)} Срок брендирования тиража — 3–5 рабочих дней через сертифицированное производство в СПб.</p>
</section>`;
}
```
