## 1. Контекст и резюме аудита (Executive Summary)

Проведен комплексный аудит живого сайта `https://salegifts.ru/` и его кодовой базы (`server/seo.js`, `server/server.js`, `public/`).

1. **Технический фундамент:** Серверный рендеринг (SSR), скорость ответа, валидный sitemap, синхронизация остатков с датами, ЧПУ и файл `/llms.txt` реализованы на высоком уровне.
2. **Критический дефицит доверия (Trust & Legal):** На сайте отсутствуют реквизиты юридического лица (ИНН, ОГРН), политика конфиденциальности и согласие на обработку персональных данных (нарушение 152-ФЗ РФ). Это сдерживает коммерческое ранжирование в Яндексе и доверие асессоров.
3. **Расщепление бренда (Entity Inconsistency):** Бренд фрагментирован между названием «СкладПромо», доменом `salegifts.ru`, контактным email на бесплатном сервисе `giftsworld1@gmail.com` и личными ссылками `vontarau`.
4. **Скрытые коммерческие условия:** Позиционирование сайта — «сувениры со склада оптом», однако оптовая шкала цен скрыта за формулировкой «Опт по запросу», нет информации о минимальной партии и нанесении логотипа.
5. **Отсутствие физической геопривязки к Санкт-Петербургу:** Телефон с кодом города (`+7 812...`) не подкреплен адресом склада, графиком работы и условиями самовывоза, что блокирует локальное ранжирование в СПб.

## 4. Архитектурный каркас страниц (Page Blueprint)

### 4.1. Главная страница (Homepage)
1. **Шапка (`header.site-header`):** Логотип, поиск по названию/артикулу, телефон СПб `+7 (812)...`, Telegram/VK, корзина.
2. **Hero-блок:** Заголовок H1, УТП склада (*«Собственный склад в Санкт-Петербурге: 4 000+ сувениров в наличии с отгрузкой за 24 часа»*), CTA в каталог.
3. **Бейджи надежности (Trust Bar):**
   - 📦 *Отгрузка за 24 часа со склада в СПб*
   - 📄 *Работаем с юрлицами (безналичный расчет, счет с НДС, УПД)*
   - 🔍 *Предоставляем образцы от 1 штуки*
   - 🎨 *Нанесение корпоративной символики (гравировка, УФ-печать, тампопечать)*
4. **Категории каталога (`section.category-directory`):** 20 плиток с фото и количеством позиций.
5. **Каталог продукции (`main.catalog-section`):** Фильтры + сетка товаров (`<article>`) с пагинацией по 20 SKU.
6. **Блок склада и самовывоза (`section.warehouse`):** Фото склада, точный адрес в СПб, интерактивная карта, график работы.
7. **Условия работы B2B (`section.b2b-terms`):** Пошаговая схема: выбор товара → согласование макета/тиража → оплата по счету → отгрузка.
8. **Подвал (`footer.site-footer`):** Реквизиты юрлица, ссылки на `/privacy` и `/delivery`, телефон, email, копирайт.

### 4.2. Карточка товара (Product Detail Page)
1. **Хлебные крошки (`nav.breadcrumb`):** Главная › Каталог › Категория › Название товара.
2. **Основной блок (`article.product-detail`):**
   - Галерея фото (зум) + бейдж *«В наличии: X шт. на складе в СПб»*.
   - Артикул, H1-название, бренд.
   - Розничная цена (1 шт.) + плашка ориентировочных скидок (от 50 шт., от 200 шт.).
   - CTA-кнопки: «В корзину», «Запросить расчет с логотипом».
3. **Быстрые факты (`dl.facts-list`):** Материал, цвет, габариты, упаковка.
4. **Спецификация (`table.product-attrs`):** Таблица технических характеристик.
5. **Брендирование (`section.branding`):** Рекомендуемые технологии нанесения логотипа для текущего материала.
6. **Доставка и оплата (`section.shipping`):** Самовывоз в СПб сегодня, доставка по РФ, счет для бухгалтерии.
7. **Форма оптового запроса (`section.product-wholesale`):** Имя, телефон, тираж, чекбокс 152-ФЗ.
8. **Часто задаваемые вопросы (`section.product-faq`):** 4–6 аккордеонов (образцы, НДС, сроки, возврат).
9. **Сопутствующие товары (`section.related-products`):** Перелинковка внутри смежных категорий.

## 5. Техническое задание для разработчика (Technical Backlog)

### 5.1. Разметка и семантика (`server/seo.js`)
1. **Контейнер карточки товара в листингах:**
   В функции `homeProductCardHtml` и `categoryPageHtml` заменить:
   ```html
   <!-- Было -->
   <div class="product-card">
   <!-- Стало -->
   <article class="product-card" itemscope itemtype="https://schema.org/Product">
   ```
2. **Машиночитаемая цена:**
   Обернуть значения цен в тег `<data>`:
   ```html
   <data class="card-price" itemprop="price" value="550">550 ₽</data>
   ```
3. **Контакты в футере:**
   Обернуть блок реквизитов и контактов в валидный тег `<address class="site-contacts">`.

### 5.2. Микроразметка JSON-LD
1. **Разметка организации и склада:**
   В `organizationLd()` добавить схему `Store` / `LocalBusiness`:
   ```json
   {
     "@context": "https://schema.org",
     "@type": ["Organization", "Store"],
     "@id": "https://salegifts.ru/#store",
     "name": "СкладПромо",
     "url": "https://salegifts.ru/",
     "logo": "https://salegifts.ru/apple-touch-icon.png",
     "telephone": "+78129621598",
     "email": "order@salegifts.ru",
     "address": {
       "@type": "PostalAddress",
       "addressLocality": "Санкт-Петербург",
       "streetAddress": "Фактический адрес склада"
     },
     "openingHoursSpecification": {
       "@type": "OpeningHoursSpecification",
       "dayOfWeek": ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday"],
       "opens": "10:00",
       "closes": "18:00"
     }
   }
   ```
2. **Разметка FAQPage на страницах товаров:**
   Добавить в `head` на карточках товаров генерацию схемы `FAQPage`:
   ```json
   {
     "@context": "https://schema.org",
     "@type": "FAQPage",
     "mainEntity": [
       {
         "@type": "Question",
         "name": "Вопрос...",
         "acceptedAnswer": {
           "@type": "Answer",
           "text": "Ответ..."
         }
       }
     ]
   }
   ```

### 5.3. Обновление эндпоинта `/llms.txt`

- Юридические данные и адрес склада в СПб.

## 6. Задачи для контент-менеджера и копирайтера (Content Tasks)

1. **Текст Политики конфиденциальности (`/privacy`):**
   Подготовить юридически выверенный текст в соответствии с требованиями Федерального закона № 152-ФЗ.
2. **Текст условий доставки и оплаты (`/delivery`):**
   - Самовывоз: адрес, схема проезда, пропускной режим, график.
   - Доставка по СПб: курьерская служба, интервалы, стоимость.
   - Доставка по России: ТК СДЭК, Деловые Линии, ПЭК (расчет сроков и трекинг).
   - Оплата: выставление счета для юридических лиц (с НДС / без НДС), онлайн-оплата картой.
3. **Матрица технологий нанесения логотипа:**
   - **Лазерная гравировка:** для металла и дерева (визитницы, брелоки, ножи, ручки).
   - **УФ-печать:** полноцветное стойкое нанесение на пластик, акрил, дерево (флешки, хабы, часы).
   - **Тампопечать:** экономичное тиражное нанесение в 1–4 цвета на мелкие изделия (ручки, открывалки, брелоки).
   - **Тиснение:** для кожи и кожзама (портфели, папки, визитницы).
   - **Шелкография / Термотрансфер:** для текстиля (сумки-холодильники, чехлы, платки).
4. **Пул вопросов для B2B FAQ:**
   - Предоставляются ли закрывающие документы (УПД, договор)?
   - Можно ли получить образец перед запуском тиража?
   - Как зарезервировать товар на время согласования оплаты?
   - Что делать в случае обнаружения брака при приемке?
